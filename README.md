# WebRouter website

Landing page options for WebRouter, a single, open standard for agents to search the web, retrieve data, crawl sites, run browser actions, and execute deep research.

- `WebRouter site option 1.html` — option 1 (served at `/`)
- `WebRouter site option 2.html` — option 2 (served at `/option-2`)
- `docs.html`, `evals.html`, `changelog.html`, `blog.html` — empty placeholder pages linked from the option 2 nav (served at `/docs`, `/evals`, `/changelog`, `/blog`)
